# Frontend - Sistema Inteligente de Lead Scoring (PluriOne)

Estructura modular preparada para la aplicación cliente en **React.js + Vite** con componentes visuales tipo Power BI y Dashboard en tiempo real.

## Módulos y Vistas Planificadas (Bloque 3):
- **Dashboard Principal**: Tarjetas KPI de conversión, pipeline de leads por estado y velocímetro de leads calientes (HOT).
- **Matriz de Prospectos (DataGrid)**: Tabla paginada interactiva con filtros por score, sector, canal e intención.
- **Detalle de Lead y Explicabilidad**: Vista 360 del prospecto, timeline de interacciones digitales y recomendaciones contextuales generadas por IA.
- **Configuración de Reglas Heurísticas y Umbrales**: Panel administrativo de asignación comercial.
